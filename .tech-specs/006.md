# PR 006 — 로컬 HTTPS와 WebTransport 접속 실험

- 상태: Planned (구현·실측 완료를 의미하지 않음)
- 단계: Phase 1
- 유형: 구현·검증
- 선행 PR: 005
- 기준: 사용자 제공 제품 비전 Draft v0.1 (2026-10-18)

## 목적

로컬 HTTPS와 WebTransport 접속 실험을 독립적으로 리뷰할 수 있는 변경으로 완료한다. 이 파일 하나를 PR 하나의 범위로 사용한다.

## 구현 및 산출물

- [ ] 실험용 HTTPS·HTTP/3 WebTransport 서버와 최소 접속 페이지를 만든다
- [ ] 도메인·DNS·인증서 발급/갱신·신뢰·오프라인 접속 후보를 기록한다
- [ ] WebTransport 기능 감지와 연결 오류를 노출한다. 인증서 우회나 휴대폰 개발 플래그에 의존하지 않는다

## 검증 및 완료 기준

- [ ] 실제 iPhone에서 보안 컨텍스트와 WebTransport Datagram 사용 가능 여부를 확인한다
- [ ] LAN 주소·인증서·방화벽·인터넷 단절 조건별 결과를 기록하고 제품 운영 가능성과 실험용 설정을 구분한다

- [ ] 실행 명령·환경·커밋·결과 및 남은 제한을 PR에 연결된 문서에 기록한다.
- [ ] 위 필수 항목이 실패하거나 실기기가 없으면 미완료로 남긴다. 추가 기능으로 실패를 덮지 않는다.

## 범위 제한

선행 PR의 인터페이스를 재사용한다. 다른 PR의 기능·후속 제품 영역·완성형 UI를 함께 구현하지 않는다. 기술 선택이 필요한 경우 최소 실험 근거와 대안을 ADR에 남기고, 제공된 문서의 후보 기술을 확정 사실로 취급하지 않는다.

## 리뷰 시 확인

구현 PR은 재현 가능한 실행 결과와 경계/실패 동작을, 검증 PR은 절차·원본 로그 또는 파형·결과표·판정을 함께 제출한다. 실측 전 성능 보장, 지원 플랫폼 확대, 제품 게이트 통과를 선언하지 않는다.
