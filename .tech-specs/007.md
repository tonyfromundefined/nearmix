# PR 007 — Worker와 AudioWorklet PCM 재생

- 상태: Planned (구현·실측 완료를 의미하지 않음)
- 단계: Phase 1
- 유형: 구현
- 선행 PR: 005,006
- 기준: 사용자 제공 제품 비전 Draft v0.1 (2026-10-18)

## 목적

Worker와 AudioWorklet PCM 재생을 독립적으로 리뷰할 수 있는 변경으로 완료한다. 이 파일 하나를 PR 하나의 범위로 사용한다.

## 구현 및 산출물

- [ ] WebTransport Datagram을 Worker에서 받아 AudioWorklet으로 전달한다
- [ ] 사용자 Start 동작으로 AudioContext를 시작하고 Stop·재시작·자원 해제를 구현한다
- [ ] 작은 초기 음량과 페이드로 클릭 신호를 출력하며 실제 출력 sampleRate를 기록한다

## 검증 및 완료 기준

- [ ] 실기기 유선 출력에서 클릭과 사인파를 확인한다
- [ ] 중복 Start·Stop·접속 해제 후 잔여 재생과 Worker 누수가 없는지 확인한다
- [ ] 48kHz와 다른 출력 sampleRate에서 속도·음정 오류를 확인하고 미지원 조건을 명시한다

- [ ] 실행 명령·환경·커밋·결과 및 남은 제한을 PR에 연결된 문서에 기록한다.
- [ ] 위 필수 항목이 실패하거나 실기기가 없으면 미완료로 남긴다. 추가 기능으로 실패를 덮지 않는다.

## 범위 제한

선행 PR의 인터페이스를 재사용한다. 다른 PR의 기능·후속 제품 영역·완성형 UI를 함께 구현하지 않는다. 기술 선택이 필요한 경우 최소 실험 근거와 대안을 ADR에 남기고, 제공된 문서의 후보 기술을 확정 사실로 취급하지 않는다.
