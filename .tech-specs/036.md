## 목적

Host 가상 MIDI와 제어 권한을 독립적으로 리뷰할 수 있는 변경으로 완료한다. 이 파일 하나를 PR 하나의 범위로 사용한다.

## 구현 및 산출물

- [ ] OS별 가상 MIDI/IAC/loopMIDI 출력 어댑터와 Note/CC 라우팅을 구현한다
- [ ] 연주자별 권한·중복 매핑·전체 정지 등 위험 조작의 제한을 정의한다
- [ ] 오디오와 분리된 제어 이벤트 경로와 설정 저장을 구현한다

## 검증 및 완료 기준

- [ ] Ableton MIDI Map으로 실제 Note/CC 전달을 확인한다
- [ ] 권한 없는 장면 전환과 잘못된 MIDI 값은 거부한다
- [ ] 제어 이벤트 폭주가 오디오에 미치는 영향을 측정한다

- [ ] 실행 명령·환경·커밋·결과 및 남은 제한을 PR에 연결된 문서에 기록한다.
