# PR 040 — 출력 sample rate와 장기 클록 드리프트 보정

- 상태: Planned (구현·실측 완료를 의미하지 않음)
- 단계: Phase 2
- 유형: 구현
- 선행 PR: 008,012,013
- 기준: 사용자 제공 제품 비전 Draft v0.1 (2026-10-18)

## 목적

출력 sample rate와 장기 클록 드리프트 보정을 독립적으로 리뷰할 수 있는 변경으로 완료한다. 이 파일 하나를 PR 하나의 범위로 사용한다.

## 구현 및 산출물

- [ ] 송신 sample clock과 실제 AudioContext sampleRate의 차이를 처리한다
- [ ] 버퍼 점유율 기반 drift 추정과 bounded resampling/보정 정책을 구현한다
- [ ] 급격한 보정의 클릭 방지·스트림 재시작·진단 값을 정의한다

## 검증 및 완료 기준

- [ ] 44.1/48kHz 출력과 합성 clock ppm 오차에서 속도·음정·큐 깊이를 검사한다
- [ ] 2시간 테스트에서 버퍼가 계속 증가/고갈하지 않는지 확인한다
- [ ] 보정으로 추가된 지연과 음질 영향을 기록한다

- [ ] 실행 명령·환경·커밋·결과 및 남은 제한을 PR에 연결된 문서에 기록한다.
- [ ] 위 필수 항목이 실패하거나 실기기가 없으면 미완료로 남긴다. 추가 기능으로 실패를 덮지 않는다.
