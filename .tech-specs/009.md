## 목적

iPhone 출력 지연과 생명주기 실측을 독립적으로 리뷰할 수 있는 변경으로 완료한다. 이 파일 하나를 PR 하나의 범위로 사용한다.

## 구현 및 산출물

- [ ] 네트워크 없는 로컬 클릭 재생으로 출력 지연을 분리 측정한다
- [ ] WebTransport 경로의 패킷·버퍼 조합별 물리 루프백을 수행한다
- [ ] 화면 잠금·악보 앱 전환·백그라운드·이어폰 분리·약한 Wi-Fi 결과를 보고서에 기록한다

## 검증 및 완료 기준

- [ ] 기기·OS·DAC별 표본과 지연분포·중단 시점·복구 시간을 남긴다
- [ ] 40ms는 탐색 목표로만 기록한다
- [ ] 실측 불가 항목은 미완료로 남기며 실제 측정 없이 통과 처리하지 않는다

- [ ] 실행 명령·환경·커밋·결과 및 남은 제한을 PR에 연결된 문서에 기록한다.
- [ ] 위 필수 항목이 실패하거나 실기기가 없으면 미완료로 남긴다. 추가 기능으로 실패를 덮지 않는다.
